## Specs

- **S1** (Issue #342 verbatim): "Phoenix records per-session Claude tokens by model and Jev calls; the voice worker reports Deepgram minutes, ElevenLabs characters and LiveKit minutes to Phoenix. A configurable price table turns usage into an estimated cost per session, available to operators (content-free)."
- **S2** (AC verbatim): "Each finished session has usage per provider and an estimated cost"
- **S3** (AC verbatim): "The voice worker report is tested in Python and accepted by Phoenix"
- **S4** (AC verbatim): "No content is stored with the usage"
- **S5** (AC verbatim): "A one-day report of real sessions gives the median cost per station"
- **S6** (parent orchestrator constraints, verbatim excerpt): "Phoenix records per session the Claude input/output/cache-read/cache-write tokens per model (patient generation, resolver, feedback, adjudicator if used) and Jev calls; the voice worker reports Deepgram audio seconds, ElevenLabs characters and LiveKit participant minutes to a new authenticated worker endpoint (reuse the existing worker-to-Phoenix auth); a configurable price table (config/runtime.exs, env-overridable, documented, defaults from current public prices with source URLs and date) turns usage into an estimated USD cost; persist one usage row per finished session in Postgres keyed by session id with NO user id and NO content (content-free per ADR-001/009); a mix task or documented SQL gives the median cost per station over a period."
- **S7** (invariants): usage belongs to `Backend.Stations` (AGENTS.md); `BackendWeb` stays thin; audio never passes through Phoenix (ADR-013 #209), so the worker reports audio usage; do not touch `session_controller.ex`, `station_controller.ex`, accounts or plugs (sibling #379).

- **L2** (2026-10-25, exploration): Claude calls all go through `StationAI.AnthropicClient` (`create_message`, `stream_message`), Jev calls through `TypesafeAdapter.execute_request/3`; neither knows the session id and several run in `Task.async` children (resolver, feedback, sentence stream, Jev groups) or a detached `Task.start` (patient audit). Decision: the `Stations` entry points mark the calling process with the session id; the recorder reads it from the process or its `$callers`, and the detached audit carries it explicitly. Counters live in an ETS table owned by `Conversation` (no change to `application.ex`). Rows are written when a session is finished, after its educational result and after a worker report, as an upsert keyed by `session_id`. `lib/mix/tasks` is outside the edit surface, so the period report is `Stations.session_cost_report/2` plus documented SQL. Jev (TypeSafe) has no public price page (`https://typesafe.ai/pricing` and `https://docs.typesafe.ai/pricing.md` answer 404 on 2026-10-25): its default price is 0 and must be set from the contract.
